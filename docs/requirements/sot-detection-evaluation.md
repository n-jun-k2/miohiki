# SOT と Detection の対応付けの検討方針

2026-11-25 にユーザーが承認。先行する [汎用 MOT の議論](../../worklog/discussions/20261125-182408-mot-requirements/conclusion.md) と [TAM 検討](../../agent_log/tam-proposal.md) を踏まえた方針。

- 初期構成は Track ごとの SOT を追跡の主体とする。Detection は新規対象の発見と、対応が明確な Track の確認・補正に使う。曖昧な Detection は無理に補正に使わず、具体的な扱いは決めていない。
- Detection による補正時は、既存合意に従って SOT を停止・再起動し、Track ID を維持する。補正の頻度や具体的な対応付け条件は未決定。
- まず SOT と Detection の対応付けで実際に生じる問題を観察し、原因に応じて対策・評価候補を絞る。TAM は評価候補として残し、初期構成への組み込みは確定しない。
- 観察する場面には、対象の交差・接近、遮蔽・検出漏れ、SOT の別対象への乗り移り、新規出現・退場を含める。SOT と Detection の BBOX、対応判断、補正・再起動、ID の変化を記録して原因を調べる。記録の形式や実装は未決定。

具体的な対応付け方式、寿命・状態遷移、評価データ、性能目標、TAM を評価する条件は今後決定する。TAM の性能向上は未検証。
