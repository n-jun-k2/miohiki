---
name: wf-report
description: 調査・議論・実験・進捗や意思決定の根拠を読み手に合わせて報告書に整理する。
---

自然文、作業ログ、調査・要件・設計・実験結果や Issue・PR を受け取り、目的、読者、保存先と参照資料を確認する。ユーザーの報告書依頼、複数 Agent の調査整理、重要な判断根拠、実験・評価の報告、後続工程に独立した報告書が必要な場合に使い、すべての作業で強制しない。単独利用ではメインが報告書を作成できる。専門 Agent への委譲が必要な場合は `project_secretary` に対象資料と編集範囲を指定し、結果を確認する。起動できなければ委譲の未実施を明示し、実行したと偽らない。

結論を先に示し、目的に応じて背景、内容、結果、分析、リスク、選択肢、推奨、決定・未決、次の対応と出典を選ぶ。事実・推測、確定・提案、調査済み・未調査、実測・期待、異なる意見を区別し、数値を捏造しない。秘密情報は記載しない。

保存が必要な場合は `worklog/reports/YYYYMMDD_{議題}.md` を使用し、同名ファイルがある場合は同一報告の更新か新規報告か確認し、既存報告書を無断で上書きしない。新規報告には重複しない名前を用いる。会話ログや議論記録を置き換えず、報告書を確定仕様として扱わない。`docs/` 正本への変更は案を提示し、承認状態を確認する。出典、未決・未検証、保存先と実施結果を報告する。
