---
name: wf-review
description: 実装担当と独立して変更、要件・設計との整合、テストと影響をレビューする。
---

自然文、変更、設計・計画やタスクを受け取り、実装担当とは別の Agent でレビューする。要件・設計との整合、不具合、セキュリティ、過剰な複雑性、テストの妥当性と影響範囲を確認する。独立 Agent を起動できなければ未実施として報告し、役割演技で代替しない。

指摘を Critical、Warning、Info に分類し、具体的な場所・根拠・影響を返す。レビュー担当はコードを変更しない。指摘への対応後は再検証・再レビューし、修正とレビューの反復は原則2回までとする。未解決の重大問題と未検証を報告する。
