---
name: wf-branch
description: 承認済み Issue の作業ブランチを安全に準備する。
---

Issue・対象計画を受け取り `.codex/guidelines/git-workflow.md` を確認する。作業ツリー、未コミット変更、既存 stash と現在のブランチを確認する。新規作業では共通ルールに従い main に切り替え、`git pull --ff-only` 後にブランチを作成する。手順前に変更した場合は対象だけを識別可能に stash し、新しいブランチで apply・確認する。無関係な変更を巻き込まない。承認された範囲で命名し作業ブランチを作成する。他者の作業を保全し、競合や権限不足、空リモートなどで基準を確定できなければ停止し報告する。既存変更を破棄しない。
