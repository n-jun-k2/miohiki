# 未決定事項・ユーザー判断

1. 初期版は既存のリアルタイムカメラに限定するか、動画・オフラインも扱うか。利用者、対象、カメラ数、対象密度、実行環境と FPS・遅延・精度の目標は何か。ユーザーに質問中。
2. Track ID の一意性範囲、再利用、再出現時の同一性、複数カメラ間の同一性をどう定義するか。
3. 状態名と遷移、寿命の単位と閾値、観測不在・ゼロ・エラー・未到着時の扱い、BBOX 不在時の出力はどうするか。
4. Detection 間の重複、クラス不一致、Track と観測の競合、対応付け・BBOX 選択をどう扱うか。ReID は必要か。
5. 遅延結果の期限、破棄・予測・遡及更新、既出力訂正、SOT 旧世代の識別・排除条件は何か。
6. 処理済みフレームを数える境界、要求中の再発行、フレーム選択と保持、停止失敗や通信障害からの回復はどうするか。
7. 入出力契約、クラス・座標・時刻の整合、通信方式、アダプタ互換性、依存の許容範囲は何か。
8. 保存内容・期間・容量・個人情報の扱い、正解規約、評価指標、試験環境と合格閾値をどう定めるか。
