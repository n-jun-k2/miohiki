# Round 2: 相互レビュー（実施済み）

- requirements_analyst: 既存合意のリアルタイム取得・表示・保存、SOT 制御を見落とした範囲外案を撤回。同一フレーム限定は遅延観測と緊張し、IoU・重複融合は密集やクラス不一致で失敗。再生試験だけでは実通信・表示・再起動を検証できない。出典: 既存要件、他 Agent の提案。
- algorithm_engineer: SOT は Track と起動世代を持つため単なる BBOX 群に平坦化できない。未実行と検出ゼロの混同は誤終了を招く。非同期再現には到着順、時刻、期限、乱数等が必要。中核の境界外にも既存の表示要件は残る。出典: 既存要件、他 Agent の提案。
- evaluation_specialist: 同一フレーム以外の遅延結果を捨てる、予測する、遡及更新する案を比較し、異時刻の暗黙の混合を避ける。重複融合は別対象の誤融合、IoU は交差や高速移動で ID 切替を起こし得る。評価は正解・遮蔽・出力時刻・無出力の規約が前提。出典: 既存要件、他 Agent の提案。
